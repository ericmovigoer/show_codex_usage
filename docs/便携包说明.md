# Codex 用量查看器

双击同目录的 `CodexUsage.exe` 运行。需要 Windows 10/11 x64、已安装并加入 PATH 的 Codex CLI，以及现有的本机 Codex 登录状态；首个适配版本为 0.169.0。无需安装 MFC 或 Visual C++ 运行库。

窗口显示 5 小时及每周剩余额度、恢复时间、可用重置总数和明细。使用 Windows 当前时区。程序只读查询，不创建对话、不发送模型请求、不兑换重置次数。

刷新间隔默认 3 秒，接受 1～3600 的整数；点击“应用”或按回车后立即生效，保存在同目录的 `CodexUsage.ini`。保存失败会提示，本次运行仍使用新设置。点击“立即刷新”读取完整明细。

完整明细在启动时、每 60 秒、重置次数变化时和手动刷新时查询。查询失败会保留旧数据并提示“数据未更新”，首次失败显示“暂无数据”。明细有单独的更新时间。

最小化后保留在任务栏，关闭窗口即退出并回收自己启动的隐藏 PowerShell 和 Codex 子进程。

若出现“拒绝访问”或进程启动失败，请在普通 PowerShell 中运行 `codex --version` 和 `codex login status` 检查安装及登录情况，并确认当前用户能正常访问其 Codex 目录。配置无法保存时，可将便携包解压到当前用户可写入的目录。

验证范围：x64 Debug/Release 已编译；模型、配置、模拟服务及持续运行测试见源码工程的验证记录。开发沙箱限制了新 app-server 对本机 Codex 目录的访问，因此真实账户额度与 CLI 显示的对照尚未完成。
